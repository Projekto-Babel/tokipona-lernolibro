# トキポナ教本 (仮)
トキポナの最新の知見を取りいれつつ、実践的なコミュニケーションのためのトキポナを日本語で学べる教本を執筆するためのリポジトリです。

## なぜ書くのか
トキポナは2001年にSonja Lang博士によって制作された計画言語で、極めてシンプルな構造と少ない単語数が特長です。標準的な文法書である"Toki Pona: The Language of Good" (lipu pu)は、英語やエスペラントなど5言語で利用可能で現在でもよく参照されていますが、日本語訳はなされておらず、日本語で利用可能なまとまった資料が存在しない状況が続いています。Youtubeなどに日本語でトキポナを紹介した動画などがありますが、トキポナの用法について網羅的に示したとは言いがたい状態です。

また、lipu puそのものも2014年の刊行で、すでに10年以上が経過しており、トキポナコミュニティが培ってきた用法や表現について反映されているわけではありません。lipu puはトキポナの歴史上欠かせない書籍の一つですが、より新しい知見を含んだ資料が求められています。

そこで、このリポジトリではトキポナの文法、単語、文字、そして実際の用例について可能な限り網羅した日本語テキストを作ることを目標にしています。これは単純にlipu puを翻訳するものではなく、執筆時点のトキポナコミュニティの最新の用法を含んだものとなる予定です。

## リポジトリの内容

- nasin/ : 文法を中心にまとめた文書です。
- nimi/ : 単語についてまとめた文書です。
- sitelen/ : トキポナで使用される文字についてまとめた文書です。
- toki/ : 用法についてまとめた文書です。
